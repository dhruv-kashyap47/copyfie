# Copyfie — Privacy

Copyfie is local-first. Clipboard history stays on this device.

## What Copyfie stores

| Data | Where | Notes |
|---|---|---|
| Text you copy | `clipboard.db` | Normalized (CRLF→LF, trailing NUL stripped), full text + a 400-char preview |
| Content hash | `clipboard.db` | BLAKE3-256; identifies duplicates |
| Source app id/name | `clipboard.db` | Exe path / bundle id / WM_CLASS and friendly name |
| Source window title | `clipboard.db` | Windows and X11 only; macOS omits it (needs Accessibility) |
| Timestamps, pin, use count | `clipboard.db` | Unix ms |
| Settings | `settings.json` | Theme, accent, retention, pause, shortcut |
| Logs | `logs/` | Startup/capture/paste outcomes, ids and reasons only |

Images and files are not captured in Milestone 1 (M2-04/M2-05). No rich text
or HTML is stored.

## What Copyfie never does

- **No telemetry, analytics, accounts, or cloud sync.** Milestone 1 makes no
  network requests at all.
- **No clipboard content in logs or error messages.** Logs contain ids,
  counts, and skip reasons.
- **No payload read before the privacy gate.** Formats are probed first.
- **No screenshots, keystrokes, or background input capture.**
- **No hidden clipboard writes.** Copyfie writes only when you paste or copy an
  item, and suppresses its own echo.

## Concealed and password-manager content

The privacy gate drops items marked as concealed **before reading the payload**:

- **Windows:** `ExcludeClipboardContentFromMonitorProcessing`,
  `ClipboardViewerIgnore`, `KeePassClipFormat`, `com.bitwarden.concealed`, and
  `CanIncludeInClipboardHistory` / `CanUploadToCloudClipboard` set to `0`
  (unreadable values fail closed).
- **macOS:** `org.nspasteboard.ConcealedType`, `TransientType`,
  `AutoGeneratedType`, 1Password, TypeIt2Me, and related markers.
- **Linux X11:** `x-kde-passwordManagerHint` presence (conservative).

Blocklist capture rules are implemented in the pipeline; the settings UI for
managing the list is M2-08. Pause capture is available in Settings and the tray.

## Data location and deletion

Windows: `%APPDATA%\com.copyfie.app\`
macOS: `~/Library/Application Support/com.copyfie.app/`
Linux: `~/.local/share/com.copyfie.app/`

Delete individual items with `Cmd/Ctrl+Backspace` in the palette. Bulk clear is
available through the `history_clear` command; a full Settings/limited-mode
button lands with M2-09/M2-15. Uninstalling keeps history by default; `--purge`
(M2-23) will delete it.

## Trial and licence (later)

The trial record and licence key live in `license/` inside the same data
directory. They contain no clipboard content, no window titles, and no machine
fingerprints. Optional seat activation sends a salted device hash and licence
id only, never clipboard data (M2-13/M2-14).
